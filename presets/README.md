# 프리비즈 목록

현재 사용 시작점은 [current-10s](current-10s/README.md)입니다. 이전 패키지는 비교를 위해 유지하며, 폴더 이름의 숫자가 높다고 현재 기본값인 것은 아닙니다. 특히 v5/v6의 빠른 컷과 실내 리빌은 현재 조합에 사용하지 않습니다.

## 현재 사용할 자료

| 패키지 | 내용 | 용도 |
|---|---|---|
| [current-10s](current-10s/README.md) | 실외 10초 + 실내 10초 + 합본 20초 | 최신 순서·좌핸들·실내 첫 컷 돌리 인을 한곳에서 사용 |
| [interior-lhd-v2](interior-lhd-v2/README.md) | I01–I06, 각 2초 + 실내 10초 | 현재 실내 독립 컷. I01은 4cm 전진, 나머지는 LHD v1과 동일 |
| [camera-only-20s-v3](camera-only-20s-v3/README.md) | 16개 컷, 20초 조합 8종 | 현재 실외 A/B 컷의 출처. **이 폴더의 옛 실내 컷은 우핸들이므로 새 작업에는 LHD v2로 교체** |

current-10s에서 쓰지 않은 실내 도어패널 I03도 [독립 MP4](interior-lhd-v2/shots/I03/preview.mp4)로 사용할 수 있습니다. 문 자체는 움직이지 않습니다.

옛 v1–v6 완성 영상을 새 좌핸들 버전으로 덮어쓰지는 않았습니다. 동일한 컷 ID라도 버전별 영상이 다를 수 있으므로 항상 **패키지 경로 + 컷 ID**로 지정하세요. `I01`은 개별 실내 전체 컷 ID이면서 일부 옛 20초 조합의 ID이기도 합니다. JSON의 `shots`와 `presets` 구분을 확인하세요.

## 컷을 조합할 때

현재 패키지는 컷당 2초지만 전체 프로젝트의 고정 규칙은 아닙니다. v5/v6처럼 길이가 다른 컷은 실제 프레임 수와 누적 시간으로 타임라인을 작성합니다. 내장 전환용 여유 프레임이 있는 원본과 잘라낸 클린 MP4의 길이를 혼동하지 않습니다. 현재 v3 클린 MP4는 120프레임이며, 기존 메타데이터 일부의 132프레임/2.2초는 전환 여유가 포함된 소스 길이입니다.

실내는 전체→디테일을 묶고, 실외는 디테일→전체로 진행할 수 있습니다. 비슷한 방향의 전체차 컷 두 개를 연달아 붙이면 하나의 움직임이 끊긴 것처럼 보일 수 있어 다른 높이나 방향의 컷을 사이에 둡니다. [제작·재조합 안내](../docs/previs-production.md)에 실행 방법이 있습니다.
