# Kling submission and review

Use the existing vehicle identity/image workflow and `future-classic-kling-prompts` for prepared assets and motion wording. This skill operates the real UI and records actual outcomes; it does not replace those reviews. Ordinary preparation remains user-manual until the owner explicitly authorizes a specific batch.

For the owner's current test profile: ONE job at a time, Kling3.0,3seconds,1080p,9:16,ONE output, Native Audio OFF and Multi-Shot OFF. The actual Generate quote must be exactly24credits. Correct mismatched options before submitting. Limit this run to FOUR submissions/96quoted credits, including poor results. After four, stop and await owner feedback. Do not turn these limits into authority for a new batch.

Portrait is an invariant of this owner's video workflow, not an optional delivery layout. Before upload, verify the actual Start Frame bytes are1080x1920 and record `settings.aspectRatio: "9:16"`. A landscape source, an Element reference selected by the owner, or a request for a front-half crop does not authorize landscape video. Prepare and review the portrait composition first; never substitute `source`/`source crop` or an agent-written batch override. Element references themselves may be landscape. Run the parent's `generation-spend-ledger.mjs reserve` geometry gate before every Generate click, including batch helpers. Confirm the uploaded portrait preview and actual provider aspect when shown. Inspect completed native dimensions before declaring success. Preserve a wrong-ratio result as held; do not propose split-screen, padding or a landscape master as the intended9:16 result without a separate owner choice.

Prepare every selected still and its prompt, inspect all four same-state Element references, register/update the intended Element, then bind it through the actual @ picker. Selecting @ → Elements → the real library card checkbox creates a noneditable tag and automatically adds the Element thumbnail; typed @name text alone is insufficient. Inspect the rendered tag label and its noneditable object node, not just a matching string. Do not add the same Element twice via the + control.

Current staged-video default is plate-free across Start Frames and all Element references. Preserve actual body badges and decals. Do not copy stale Future Classic plate-preservation text into a plate-free prompt. Malformed-lettering inputs stay held. Wiper readiness follows source-documented resting geometry; on2026-10-25 the Jeep owner revoked the low-horizontal override. Diagonal rest angles are not a failure by themselves.

Read [browser-runbook.md](references/browser-runbook.md) for the verified UI path and bounded observations. Reuse the current IAB tab and authentication. Capture current modal/composer state after changes; use semantic names where supported and current screenshots for icon-only controls. Cached coordinates/indices are hints, not truth. Do not read private app stores, guess endpoints or bypass the visible UI.

Reserve a local attempt before ONE Generate click; save input/reference hashes, prompt, actual tag evidence, exact quote/settings and submission time. Reconcile the new queued card/job URL without repeating the click. If acknowledgement is ambiguous, hold the intent until real history establishes the outcome.

Once submission is confirmed, check that job only every FIVE MINUTES, measured from submission and then from each check. Generation can take30minutes or longer: a pending job schedules another five-minute check, never a resubmission. Do useful local work between checks. Waiting and UI interaction are separate; local state checks do not inspect Kling. Avoid repeated full history snapshots and unchanged-progress narration.

After completion, save the actual native clip and job URL. For owner delivery/editing use the provider's official Without Watermark download option, enabled and checked before every download; the default Download action can produce branded bytes even on this account. Verify the actual downloaded frames and retain separate hashes for branded versus clean variants. Do not crop or erase a watermark as a substitute for the official export. Review playback and start/middle/end frames for camera orbit versus zoom/tracking, actual viewpoint/parallax, vehicle world position/orientation, tire contact/rolling, body/lettering/wipers/lamps and crop. Record the actual result and its limits before the next submission. A good result informs the next different shot; a poor result also moves to another photo, with the smallest relevant prompt correction. No immediate same-photo retry in this run. No silent speed-up or local zoom as a substitute for failed orbit.

Use `scripts/kling-run-state.mjs` for the local four-job/poll/review state gate and the parent's generation-spend-ledger for provider/accounting evidence. These tools check recorded facts, not image/video truth, and never click Generate or contact Kling. Exact charges/tokens remain unknown unless observed; a24credit quote is not a fabricated exact balance debit.

Commands: `init state.json authorization.json`, `reserve state.json preflight.json`, `ack state.json observed-job.json`, `due state.json`, `check state.json status.json`, `review state.json review.json`. Record provider ID only when observed. A reserved/unknown outcome blocks another job. Persist state, selected images, current Element name and next-check time across context resets; do not restart the batch.

Use `scripts/review-native-video.py --input actual.mp4 --out review-folder --ffmpeg actual-executable` after download. It records native file hash, dimensions, duration, audio presence and seven timestamped frames/contact sheet. Format checks are automatic; the main agent supplies the visual motion/identity verdict after inspecting actual media. A queued card can be acknowledged with observed evidence while taskId remains null; keep the same pending job and record its real ID when the detail URL exposes it.

For the inspected Jeep garden examples, read [jeep-garden-tests.md](references/jeep-garden-tests.md). Constant-distance and tiny-angle language did not reliably enforce the desired motion; keep observed improvements separate from proven causes.
