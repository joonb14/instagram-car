# 카메라만 움직이는 20초 프리셋

`index.html`을 브라우저로 열면 실내 포함/미포함으로 선택할 수 있습니다. MP4·Start PNG·prompt.txt·recipe.json은 각 폴더에 있습니다.

차량, 휠, 배경, 문과 실내 조작부는 정지하고 카메라만 움직입니다. 실내는 기어봉·버튼·키·손잡이 디테일 없는 기본 덩어리입니다. 차량 사진 없이 실제 차의 실내와 일치한다고 주장하지 않습니다. 팔과 손은 없습니다.

8개 모두 1080×1920, 60fps, 무음, 1200프레임=20초입니다. 각 프리셋은 서로 다른 순서의 10컷×2초입니다. 4개 외관 프리셋은 동일한 10개 각도를 순서만 바꾸고, 4개 실내 포함 프리셋은 서로 다른 실내·외관 조합입니다.

이는 직접 만든 프록시 3D 렌더이며 특정 차종 모델이나 원본 영상이 아닙니다. E30/997/964 등의 실차 사진과 생성된 최종 영상은 포함하지 않습니다. 실내 프리셋에는 대상 차량의 실제 대시보드·문·센터콘솔·시트 사진이 필요합니다. 수동/자동 기어를 가정하지 않습니다.

제작: `tools/previs/build_camera_presets.py`를 검증된 Blender MCP 인스턴스에서 실행 → `render_camera_presets.py`로 CLI 렌더 → `package_presets.py --library .local/previs/preset-camera-v001`. 재생성에는 기존 private generic proxy Blender 라이브러리가 필요하지만, 이 폴더의 완성된 MP4/HTML은 독립적으로 사용할 수 있습니다. 최초 소스 분석 레퍼런스: FIAMRACING의 eaq0oFtTaQs, NHWZKfeyJII. 원본 프레임이나 오디오를 복사하지 않았습니다.

검증: 전체 MP4 디코딩·형식·프레임수·SHA256. Blender 장면의 비카메라 객체 애니메이션 제거 및 월드 변환 검증은 비공개 실행 기록에 보관합니다. 사용자 최종 시각 승인은 별도입니다.
