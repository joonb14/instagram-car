# 구도를 유지한 카메라·전환 프리셋

index.html: 왼쪽 재생, 오른쪽 컷별 설명/프롬프트/타임라인. 전환 시안과 생성 입력용 클린 버전을 전환할 수 있습니다. 8개 조합은 각각 20초, 1080×1920, 60fps, 무음입니다. shots/에는 재조합할 수 있는 16개 개별 클린 컷과 1080×1920 시작 PNG가 있습니다.

전체차는 실제 차체 중심 수평 아크, 상부는 위에서 아래로 수직 아크, 측면은 위에서 내려와 기존 측면 구도에 도착합니다. 휠은 고정한 채 뒤로 빠져 펜더와 차체를 드러냅니다. 전면과 실내는 선택한 대상을 유지하는 짧은 이동입니다. 기존 v1의 60프레임 구도를 시작점으로 사용하며 A10은 도착점으로 사용합니다. 차량·휠·실내 부품은 모두 정지합니다. 렌즈 줌은 없습니다.

전환은 9개 경계마다 명시했습니다. 직접 컷을 기본으로, 일부 전체차 연결에 0.2초 디졸브와 실내 진입/이탈에 짧은 암전을 사용합니다. 전환은 편집 효과이며 실물의 움직임이 아닙니다. 이중 노출/형태 변형이 생성에 전파되지 않도록 생성에는 clean.mp4와 prompt.txt를 권장합니다. 결과물 조합 단계에 recipe.json 전환을 적용하세요. 핸들을 겹쳐도 길이는 정확히 1200프레임입니다.

대상 실차 사진은 포함하지 않습니다. Start PNG는 프록시 구도 참고용으로 실제 차량 사진 기반 Start Frame을 대신하지 않습니다. 실내는 범용 덩어리이므로 실제 차량 실내 사진이 별도로 필요합니다.

제작: direct_camera_presets.py (검증된 MCP) → render_camera_presets.py → package_camera_treatments.py. 이전 v1·v2는 보존합니다. Blender/실행 기록은 .local/previs/preset-camera-v003에 보관합니다.
