# 현재 프리비즈 · 실외 10초 / 좌핸들 실내 10초

[로컬 플레이어](index.html) · [실외 MP4](EXTERIOR/previs.mp4) · [실내 MP4](INTERIOR/previs.mp4) · [20초 검토본](REVIEW/combined-20s.mp4)

모두 직접 제작한 범용 3D 프록시입니다. 현재 G500 작업에서 정리한 컷 배치를 재사용하지만, 실제 G500 사진이나 생성 영상은 포함하지 않습니다. 다른 차량도 해당 차의 외관·실내 사진과 함께 적용할 수 있습니다. 새 조합의 사용자 시각 승인은 아직 별도입니다.

| 시간 | 실외 | 실내 |
|---|---|---|
| 0–2초 | A06 헤드라이트 · 짧은 슬라이드 | I01 실내 전체 · 짧은 돌리 인 |
| 2–4초 | A07 뒤 휠 · 대각선 풀백 | I05 핸들 · 짧은 접근 |
| 4–6초 | A03 뒤 사선 전체 · 수평 아크 | I02 콘솔 · 짧은 슬라이드 |
| 6–8초 | A08 상부 · 하강 수직 아크 | I04 시트·콘솔 · 짧은 슬라이드 |
| 8–10초 | A11 낮은 후면 전체 · 수평 아크 | I06 조수석 대시보드 · 가로 이동 |

실외는 두 후면 컷 사이에 상부 구도를 넣었습니다. 실내 I01은 기존 첫 구도를 유지한 채 4cm 앞으로 이동합니다. 렌즈와 방향은 고정하고, 뒤로 빠지며 새로운 실내 영역을 드러내지 않습니다. 모든 물체는 정지합니다.

각 편은 1080×1920, 60fps, 600프레임, 무음입니다. 합본은 1200프레임이며 생성용 길이 제한과 별개인 흐름 검토본입니다. 프록시 시작 PNG는 [실외](EXTERIOR/start.png)와 [실내](INTERIOR/start.png)에 있습니다.

프롬프트: [실외](EXTERIOR/prompt.txt) / [실내](INTERIOR/prompt.txt). 조합: [실외 recipe.json](EXTERIOR/recipe.json) / [실내 recipe.json](INTERIOR/recipe.json). 프롬프트에는 특정 서비스에서 확인되지 않은 Element 태그를 넣지 않았습니다. 실제 생성 시 사진 첨부·태그·10초·9:16 설정을 맞춥니다.

실외 개별 컷은 `../camera-only-20s-v3/shots/`, 실내 개별 컷은 `../interior-lhd-v2/shots/`를 참조합니다. 이 폴더만 옮기면 개별 컷 링크가 끊기므로 저장소 구조를 유지하세요. 조합 MP4는 단독 파일로 사용할 수 있습니다.

제작 코드: [package_current_pair.py](../../tools/previs/package_current_pair.py). 이미 렌더된 Git의 클린 컷을 순서대로 연결하며 새 렌더나 재인코딩을 하지 않습니다. 전체 디코딩으로 크기·fps·무음·프레임 수를 검사하고, 연결 전후 프레임 해시가 순서대로 같은지 확인합니다. 실행 기록은 `.local/previs/current-pair-packaging/`에 보관합니다.

재조합 명령과 실제 Blender 제작 과정: [제작 안내](../../docs/previs-production.md).
