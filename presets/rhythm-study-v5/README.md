# 컷의 호흡을 달리한 30초 시안

FULL은 30초, PART1은 20초, PART2는 10초입니다. 모두 1080×1920, 60fps, 무음이며 각 파일에 프롬프트가 있습니다.

| 컷 | 길이 | 내용 |
|---|---|---|
| A06 | 1.2초 | 헤드라이트 · 라인 따라 슬라이드 |
| W01 | 1초 | 앞 휠 · 짧은 접근 |
| A07 | 2.8초 | 뒤 휠 · 펜더 풀백 리빌 |
| I01 | 2.4초 | 실내 전체 · 짧은 풀백 |
| I05 | 1.2초 | 스티어링 · 짧은 접근 |
| I07 | 1.8초 | 실내 중간 거리 · 시트와 콘솔 |
| I02 | 1초 | 센터콘솔 · 형태 따라 슬라이드 |
| I03 | 1초 | 도어패널 · 깊이를 보여주는 슬라이드 |
| I04 | 1.2초 | 시트 · 시트와 콘솔 사이 슬라이드 |
| I06 | 1.4초 | 대시보드 · 라인 따라 슬라이드 |
| T01 | 1초 | 테일램프 · 후면 디테일 |
| A08 | 2초 | 상부 · 위에서 아래로 수직 아크 |
| B08 | 2초 | 뒤 데크 · 원경 하강 수직 아크 |
| A02 | 2.8초 | 전면 사선 · 보닛 하강 수직 아크 |
| A03 | 3.2초 | 후면 전체 · 수평 아크 |
| A11 | 4초 | 로우 후면 · 수평 아크 |

새 컷은 W01 앞 휠 접근, I07 시트·콘솔 중간 거리, T01 테일램프 디테일입니다. 기존 경로는 새 길이에 맞춰 Blender에서 60fps로 다시 샘플링·렌더했습니다. 인코딩된 영상의 프레임을 복제해서 늘리지 않았습니다. 실내는 한 구간에 모았고 외관은 마지막 전체차로 확대됩니다. A11은 4초로 마무리합니다.

시작 PNG는 범용 프록시 구도용입니다. 실제 차의 외관·실내 사진은 별도 입력입니다. 차량·휠·문·실내 조작부는 모두 고정합니다. 이전 v4를 보존했습니다.
